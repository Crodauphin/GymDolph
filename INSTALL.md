# Gym Dolph v0.8 — Install

## Files
Upload all files to your GitHub Pages repo root (flat structure, no subfolders).

Add your app icons:
- `icon-192.png` — 192×192 app icon
- `icon-512.png` — 512×512 app icon

## Install on Android
1. Open the GitHub Pages URL in Chrome
2. Tap ⋮ → "Add to Home Screen"
3. The app installs as a PWA — works offline

## Sync phone ↔ tablet
Settings → Export Data (JSON) on one device → open file on other → Import Data
